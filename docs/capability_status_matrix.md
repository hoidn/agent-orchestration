# Capability Status Matrix

What each authoring and runtime surface does today, whether to use it for new
work, and where to read more. `specs/` defines behavior; if this table
disagrees with a spec, the spec is right and the table needs fixing.

Status labels:

- `Implemented`: works in this checkout and has tests.
- `Partial`: works for the stated subset; the notes give the limit.
- `Library`: provided by the standard library, not by a compiler form.
- `Designed`: a design exists; nothing is implemented.
- `Future`: intentionally deferred.
- `Retired`: removed from the product; remaining references are history.
- `Legacy`: still runs for compatibility; do not start new work with it.

Choose an execution profile by need: typed targets give checked types and
resume; native 3.0 gives ordinary functions and closures with fresh-only runs.
